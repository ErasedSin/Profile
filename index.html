02 · Método

Método de trabalho.

  1. 01

    Entender antes de mudar

    Antes de alterar o código, identifico a causa raiz com logs, medições e comparação entre cenários que funcionam e que falham. Muitos problemas se revelam de configuração, e não de código.

  2. 02

    Uma mudança de cada vez

    Cada correção é testada isoladamente, com comparação de antes e depois, para confirmar o seu efeito. Tentativas sem resultado também são documentadas, para evitar retrabalho.

  3. 03

    Foco no usuário

    Mensagens de erro claras, configurações acessíveis por interface gráfica e documentação em linguagem simples. É onde suporte e desenvolvimento se encontram.

03 · Projetos

Projetos.
Problema, solução e resultado.

  1. 01 · Port nativo para PC · Desempenho C++ · C# · CMake · DirectX 12

    Erased Reboot Version

    Guitar Hero: Warriors of Rock e Guitar Hero 5, de Xbox 360, recompilados para rodar nativos no PC, com um launcher próprio para os dois jogos.

    Problema
    O port existente tinha problemas de desempenho, reproduzia apenas a faixa de áudio da guitarra e não era compatível com guitarras e controles comuns de PC.
    Solução
    Análise de desempenho de CPU, GPU e tempo de quadro, seguida de correções em C++ na sincronização de threads, na resolução interna e no relógio do jogo. Desenvolvimento de um launcher em C# com perfis por jogador, conquistas, DLC e atualização automática.
    Resultado
    Melhor desempenho, suporte a mais de 60 FPS mantendo a sincronia, áudio completo das faixas e a versão 2.2 publicada e em uso por outros jogadores.
    • Controles: guitarras de verdade, controle comum ou teclado como guitarra, guitarras USB genéricas configuradas botão por botão e guitarra pelo Parsec
    • Menu de debug do jogo liberado comparando duas versões do executável instrução por instrução
    • Online experimental e DLC compartilhado entre os dois jogos

    Baseado no re-wor (ronniecloud), no re-gh2 e no ReXGlue SDK, com partes do GHVanHRecomp e do GH5Recomp (ElGuslml). Não inclui arquivos dos jogos.

    Código Versões
  2. 02 · Back-end · Regras de negócio Python · FastAPI · SQLite · Docker

    Sistema de Ordens de Serviço

    Sistema para uma assistência técnica de computadores: clientes, equipamentos e ordens de serviço com histórico de status.

    Problema
    Assistências técnicas de pequeno porte costumam controlar os serviços em papel, perdendo o histórico de cada equipamento.
    Solução
    API REST com regras de transição de status, banco SQL com chaves, restrições e índices, relatório por consulta SQL, tela web com login, Docker e CI.
    Resultado
    20 testes automatizados com pytest cobrindo as regras de negócio.
    Código
  3. 03 · Ferramenta de suporte · Automação Python · PowerShell · HTML

    Diagnóstico de PC

    Ferramenta que levanta o estado de um computador com Windows e gera um relatório em HTML para o técnico.

    Problema
    No suporte técnico, boa parte de cada atendimento é gasta levantando informações de hardware, armazenamento e memória e identificando falhas.
    Solução
    Coleta pelo PowerShell (CIM), análise em Python sem bibliotecas externas e relatório em HTML com os alertas no topo.
    Resultado
    54 testes automatizados e um relatório adequado para entrega ao cliente.
    Código
  4. 04 · App web · Armazenamento offline JavaScript · WebAssembly · IndexedDB

    GBA Player

    Player de Game Boy Advance que roda no navegador. O emulador é o mGBA, em WebAssembly; a interface em volta dele é o meu projeto.

    Problema
    Emuladores no navegador costumam perder o progresso salvo e não informam o motivo quando falham ao iniciar.
    Solução
    Lê o cabeçalho do jogo no navegador, guarda os saves no IndexedDB com sincronização automática e baixar/enviar o .sav, controles de teclado e toque, escala de 1x a 5x e uma tela de título que confere threads, WebGL2 e arquivos e explica qualquer falha.

    Núcleo de emulação: mGBA (MPL-2.0). O site não inclui jogos.

  5. 05 · Front-end · PWA HTML · CSS · JavaScript · SVG · Canvas

    PerfilSelection

    Página de links interativa: a pessoa monta a própria página num editor, sem mexer em código.

    Problema
    Os serviços de página de links existentes oferecem pouca personalização e exigem cadastro.
    Solução
    Reconhece a rede social pelo link colado e busca a foto do perfil, cinco formatos (órbita, árvore, sistema solar, constelação e espiral), fundos animados em Canvas e linhas em SVG, salvamento automático, link compartilhável e instalação como app no Android.
