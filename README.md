# Portfólio · Gaio Moreira

Meu portfólio pessoal. Abre com uma intro inspirada nas aberturas de missão de jogos de tiro antigos: data, local e coordenadas digitados na tela, o nome completo aparecendo letra por letra e depois virando as iniciais, que vão parar no logo do topo.

Feito com HTML, CSS e JavaScript puro, sem framework.

- A intro roda uma vez por visita. Dá pra pular com Esc e rever pelo rodapé.
- Quem tem "reduzir movimento" ligado no sistema vai direto pro conteúdo.
- Os projetos aparecem como missões: o problema, o que eu fiz e o resultado.
